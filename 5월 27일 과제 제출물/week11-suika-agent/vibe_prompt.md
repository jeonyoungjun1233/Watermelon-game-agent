# 바이브코딩 프롬프트

아래 프롬프트를 기준으로 `my_agent.py` 첫 버전을 만든다.

```text
너는 괴짜 개발자 콩쌤 수박게임 프로젝트의 Week 11 과제용 코딩 에이전트다.

먼저 계획을 세우고, 그 다음에 코드를 작성해라.

목표:
- 일정공지 에이전트 예시를 수박게임 작업공지 에이전트로 바꾼다.
- 같은 폴더의 context.md와 todo.md를 읽어서 작업 맥락으로 사용한다.
- 외부 패키지 없이 실행되는 Python 파일 my_agent.py를 만든다.
- 최소 3개 이상의 함수로 역할을 나눈다.
- 실행 중간 결과를 콘솔에 출력한다.
- 원래 게임 코드(src/main.js, src/style.css, index.html, public, package.json)는 수정하지 않는다.
- 규칙 기반 v0와 12주차 Groq API/외부 도구 확장의 차이를 보고서에 정리한다.
- 실행 후 agent_output.md를 생성한다.

코드 작성 전 계획:
1. 현재 폴더의 준비 파일 4개를 확인한다.
2. context.md와 todo.md를 읽는 함수를 만든다.
3. 수박게임 프로젝트 루트를 찾고 핵심 파일을 점검하는 함수를 만든다.
4. 일정공지 에이전트 구조를 수박게임 작업공지 에이전트 구조로 바꾸는 함수를 만든다.
5. 규칙 기반 v0 계획과 12주차 확장 결정을 생성하는 함수를 만든다.
6. 콘솔 중간 출력과 agent_output.md 저장을 구현한다.
```
