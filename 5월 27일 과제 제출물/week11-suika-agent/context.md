# 프로젝트 컨텍스트

## 프로젝트 이름

괴짜 개발자 콩쌤 수박게임

## 원래 게임 구조

이 프로젝트는 Vite, JavaScript, Matter.js, HTML Canvas로 만든 수박게임 스타일의 웹 게임이다. 같은 얼굴 공 2개가 합쳐지면 다음 단계의 얼굴로 진화하고, 점수가 올라가며, 최종 단계에서는 축하 연출이 나온다.

원래 게임 코드의 핵심 파일은 다음과 같다.

- `index.html`: 브라우저 진입점
- `src/main.js`: Matter.js 물리 엔진, 공 생성, 병합, 점수, 오디오, 캔버스 렌더링
- `src/style.css`: 세로형 게임 화면, 점수판, 진화 가이드, 시작/축하 오버레이 스타일
- `public/faces`: 단계별 얼굴 이미지
- `public/media`: 효과음, 배경음, 축하 영상
- `package.json`: Vite 실행과 빌드 스크립트

## Week 11 작업 목표

이번 작업은 게임 기능을 바꾸는 일이 아니라, 기존 게임 프로젝트를 주제로 한 에이전트 구조를 만드는 과제다. 일정공지 에이전트 예시를 수박게임 작업공지 에이전트로 바꾸고, 코딩 에이전트가 읽을 수 있는 맥락 파일과 작업 파일을 제공한다.

## 일정공지 에이전트에서 바꾼 점

| 일정공지 예시 | 수박게임 에이전트 v0 |
| --- | --- |
| 수업 일정과 공지 대상 확인 | 게임 코드와 과제 체크리스트 확인 |
| 날짜, 장소, 준비물 정리 | 파일 구조, 금지 수정 범위, 산출물 정리 |
| 공지 문구 생성 | 작업 계획과 12주차 개선 계획 생성 |
| 사람이 다시 확인 | 실행 결과와 `todo.md` 체크리스트로 검토 |

## v0 에이전트 범위

`my_agent.py`는 규칙 기반 v0이다. 외부 LLM이나 외부 도구를 호출하지 않고, 로컬 파일과 정해진 규칙만 사용한다. 그래서 API 키가 없어도 실행되고, 다른 폴더로 옮겨도 기본 보고서를 만들 수 있다.

## 수정 원칙

- 기존 게임 실행 파일은 수정하지 않는다.
- 에이전트 과제 산출물은 이 폴더 안에 모은다.
- `context.md`와 `todo.md`는 에이전트에게 제공하는 공유 메모리 역할을 한다.
- 실행 결과를 보고 다음 주 개선 항목을 `todo.md`에 남긴다.
