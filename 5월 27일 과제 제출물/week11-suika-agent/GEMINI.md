# Gemini 보조 검토 규칙

Gemini 또는 다른 보조 에이전트가 이 폴더를 검토할 때는 아래 기준으로 확인한다.

## 확인 기준

- `my_agent.py`가 외부 패키지 없이 실행되는가?
- 함수가 최소 3개 이상 역할별로 분리되어 있는가?
- `context.md`와 `todo.md`를 실제로 읽는가?
- 실행 중간 결과가 콘솔에 출력되는가?
- `agent_output.md`가 생성되는가?
- 일정공지 에이전트 예시가 수박게임 작업공지 에이전트로 바뀌었는가?
- 12주차에 Groq API를 붙일지, 외부 도구를 붙일지 결정되어 있는가?
- 다음 주 개선 항목이 `todo.md`에 남아 있는가?

## 금지 사항

- Week 11 과제 범위를 넘어서 게임 기능을 바꾸지 않는다.
- API 키를 코드나 문서에 직접 넣지 않는다.
- 외부 패키지 설치를 전제로 검토하지 않는다.
- 확인하지 않은 실행 결과를 완료처럼 말하지 않는다.
