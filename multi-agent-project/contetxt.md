# 프로젝트 컨텍스트

이 파일은 강의나 제출 과정에서 `context.md`가 `contetxt.md`로 적힌 경우를 대비해 함께 둔 호환용 문서이다. 실제 기준 문서는 `context.md`이며, 아래 내용은 같은 프로젝트 배경을 요약한다.

## 프로젝트 개요

`콩쌤 수박게임`은 Vite, JavaScript, Matter.js, HTML Canvas로 만들어진 웹 게임이다. 이번 과제에서는 게임 기능을 변경하지 않고, 멀티에이전트 협업 프로젝트로 제출할 수 있도록 문서 구조를 추가한다.

## 멀티에이전트 구성

- 프로젝트 매니저 에이전트: 요구사항과 제출 범위 관리
- 개발 에이전트: 코드 구조 이해와 안전한 변경 제안
- QA 에이전트: 빌드와 게임 동작 확인
- 문서화 에이전트: GitHub 제출 문서 작성
- 리뷰 에이전트: 변경 범위와 회귀 위험 검토
- Week 11 규칙 기반 에이전트: `week11-suika-agent` 폴더에서 문서 맥락을 읽고 실행 보고서를 생성

## 핵심 제약

게임 화면, 조작, 물리 엔진, 점수, 소리, 이미지, 영상은 그대로 유지한다. 이번 작업은 `multi-agent-project` 폴더 안의 문서 작성에만 해당한다.

`week11-suika-agent`는 같은 이름의 문서를 내부에 따로 보관하는 독립 모듈이므로, 상위 `context.md`, `todo.md`, `AGENTS.md`, `GEMINI.md`와 섞어 쓰지 않는다.

## 제출용 설명

기존 게임 프로젝트에 AI 에이전트 협업 구조를 도입한 과제이다. 실제 코드는 변경하지 않고, 에이전트별 역할, 작업 계획, 검토 기준을 Markdown 문서로 정리했다.
