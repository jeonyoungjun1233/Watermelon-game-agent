# GEMINI 작업 지침

## 역할

Gemini는 이 프로젝트에서 보조 분석 및 문서 검토 에이전트로 동작한다. 주요 임무는 요구사항을 다시 정리하고, 문서가 과제 제출 목적에 맞는지 확인하며, 게임 코드에 영향을 줄 수 있는 변경을 경고하는 것이다.

## 반드시 지킬 규칙

- 게임 동작을 바꾸지 않는다.
- `src`, `public`, `index.html`, `package.json`, `package-lock.json`은 수정하지 않는다.
- 문서 작업은 `multi-agent-project` 폴더 안에서만 수행한다.
- 답변과 문서는 한국어로 작성한다.
- 과제 제출자가 설명하기 쉬운 단어를 사용한다.
- 확인하지 않은 사실을 완료된 작업처럼 말하지 않는다.

## 확인할 프로젝트 맥락

이 저장소는 콩쌤 캐릭터 이미지와 효과음을 사용하는 수박게임 프로젝트이다. 핵심 게임 로직은 `src/main.js`에 있고, 화면 스타일은 `src/style.css`에 있다. 이번 멀티에이전트 작업은 게임 기능 추가가 아니라 협업 문서 작성이 목적이다.

## Gemini가 맡는 작업

1. `todo.md`의 작업 목록이 과제 요구사항과 맞는지 검토한다.
2. `context.md`에 프로젝트 배경, 기술 스택, 제약 조건이 충분한지 확인한다.
3. `AGENTS.md`의 에이전트 역할이 서로 겹치지 않는지 확인한다.
4. `week11-suika-agent` 모듈이 상위 문서와 파일명이 충돌하지 않게 분리되어 있는지 확인한다.
5. 제출 전에 게임 관련 파일이 변경되지 않았는지 확인하도록 안내한다.

## Week 11 모듈 검토 기준

- `week11-suika-agent/my_agent.py`가 외부 패키지 없이 실행되는가?
- `week11-suika-agent/context.md`와 `week11-suika-agent/todo.md`가 모듈 안에서 독립적으로 읽히는가?
- 실행 결과가 `week11-suika-agent/agent_output.md`에만 저장되는가?
- 상위 `AGENTS.md`, `GEMINI.md`, `context.md`, `todo.md`를 덮어쓰지 않았는가?

## 응답 형식

검토 결과는 아래 형식으로 작성한다.

```md
## 검토 결과

- 통과:
- 수정 필요:
- 게임 영향 여부:
- 제출 전 확인:
```

## 금지 작업

- 게임 난이도, 점수, 이미지, 오디오, 물리값 수정
- 새로운 라이브러리 설치
- 빌드 설정 변경
- 불필요한 리팩터링
- 과제와 무관한 기능 추가
- 하위 모듈의 실행 결과를 상위 문서 내용처럼 섞어 쓰기
