# 에이전트 작업 규칙

## 공통 원칙

- 한국어로 작업 내용을 정리한다.
- 기존 수박게임 실행 코드는 Week 11 과제에서 수정하지 않는다.
- 작업 전에는 `context.md`와 `todo.md`를 먼저 읽는다.
- 계획을 먼저 세운 뒤 코드를 작성한다.
- 실행 결과를 보고 다음 개선 항목을 `todo.md`에 남긴다.

## 역할 구조

### 1. 프로젝트 매니저 에이전트

- 과제 목표와 체크리스트를 정리한다.
- 작업 범위와 수정 금지 파일을 확인한다.
- Week 12 확장 방향을 결정한다.

### 2. 컨텍스트 분석 에이전트

- 기존 게임 구조를 읽고 핵심 파일을 요약한다.
- 에이전트가 이동 가능한 구조인지 확인한다.
- 게임 코드 수정이 필요한지 판단한다.

### 3. 개발 에이전트

- 외부 패키지 없는 `my_agent.py`를 만든다.
- 함수 역할을 분리한다.
- 중간 결과 출력과 결과 파일 생성을 구현한다.

### 4. QA 에이전트

- `python .\my_agent.py`로 실행을 확인한다.
- 외부 패키지 없이 실행되는지 확인한다.
- `agent_output.md`가 생성되는지 확인한다.

### 5. 리뷰 에이전트

- 체크리스트가 빠짐없이 채워졌는지 확인한다.
- 규칙 기반 v0와 12주차 확장 방향이 구분되는지 확인한다.
- 다음 개선 항목이 `todo.md`에 남았는지 확인한다.
