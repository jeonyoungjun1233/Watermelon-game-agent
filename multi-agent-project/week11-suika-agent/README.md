# Week 11 수박게임 멀티에이전트 제출물

이 폴더는 `괴짜 개발자 콩쌤 수박게임` 프로젝트를 주제로 만든 Week 11 멀티에이전트 과제 제출물이다.

## 이번 수정에서 반영한 피드백

- 설계 문서의 5개 에이전트를 실제 `my_agent.py` 코드에 클래스로 구현했다.
- 각 에이전트는 `run(self, state)` 메서드를 가지고, 하나의 공유 `state` dict를 읽고 쓴다.
- 멀티에이전트가 필요한 이유를 단일 에이전트의 한계와 함께 다시 정리했다.
- QA는 사실 검증, 최종 리뷰는 형식과 톤 검토로 역할을 분리했다.
- 시장형 패턴은 후보와 평가 기준이 있을 때만 쓰도록 기준을 추가했다.

## 파일 구성

- `my_agent.py`: 5개 에이전트를 실제로 실행하는 Python 코드
- `agent_output.md`: `my_agent.py` 실행 결과로 생성된 제출 보고서
- `context.md`: 에이전트가 참고하는 프로젝트 배경
- `todo.md`: 과제 체크리스트와 다음 개선 항목
- `AGENTS.md`: 공통 작업 규칙
- `GEMINI.md`: 보조 에이전트 규칙
- `vibe_prompt.md`: 이전 에이전트 생성 프롬프트 기록

상위 폴더의 `multi-agent-design.md`는 최종 설계 문서다.

## 실행 방법

```powershell
python .\my_agent.py
```

실행하면 5개 에이전트가 순서대로 공유 상태를 넘겨받고, 결과를 `agent_output.md`에 저장한다.

## 주의 사항

게임 실행 코드는 수정하지 않는다. 이 제출물은 게임 기능을 바꾸는 작업이 아니라, 게임 프로젝트를 기반으로 멀티에이전트 설계와 구현 예시를 정리하는 작업이다.
